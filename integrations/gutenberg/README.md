# Gutenberg — clássicos brasileiros

Fonte experimental de EPUBs reais de domínio público, com seleção inicial de duas obras originais de Machado de Assis:

- Dom Casmurro: https://www.gutenberg.org/ebooks/55752
- Memórias Póstumas de Brás Cubas: https://www.gutenberg.org/ebooks/54829

O catálogo pequeno é hospedado como JSON no repositório do Acervo e filtrado localmente. O arquivo é servido pelo espelho https://gutenberg.pglaf.org/, não pelo site principal. Ambos os EPUBs foram verificados via HTTPS e apresentaram o mimetype EPUB esperado em 2026-11-24. Não são redistribuídos pelo Acervo. Verifique os direitos da edição em seu país e preserve os avisos do arquivo.

Política: https://www.gutenberg.org/policy/terms_of_use.html

A API Gutendex excedeu o tempo de resposta durante a validação; a pesquisa no catálogo completo não está implementada. Esta fonte é uma primeira integração real, não substitui a API completa.

Instale pela área Extensões → Gutenberg (ou importe manifest.json), selecione a fonte em Descobrir e pesquise Machado de Assis, Dom Casmurro ou Memórias Póstumas. Teste primeiro em uma biblioteca descartável.
